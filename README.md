## Objetivo
Clasificar el subtono de una persona (Warm, Cool o Neutral) a partir de rasgos
como color de cabello, ojos, piel, largo del torso y proporción corporal, para
recomendarle la paleta de colores de ropa que mejor le favorece.

## Dataset
`recommendations.csv` (15.120 filas × 18 columnas).
Fuente: [https://www.kaggle.com/datasets/suryaprabha19/fashion-and-color-recommendation-dataset]
